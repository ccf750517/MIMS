# MIMS — 量測儀器管理系統

目前版本：**v0.1.115**。應用程式完整保留在 `index.html`，可離線使用，無需安裝前端套件或後端資料庫。

## 執行

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory /workspace/MIMS
```

資料儲存在瀏覽器 localStorage，依通訊協定、網域、連接埠與瀏覽器設定檔隔離。更換開啟方式前請先匯出 JSON 備份。GitHub 上的 HTML 不包含瀏覽器內的使用者資料。

## v0.1.115 行為

- JSON 匯入先驗證儀器與明細結構、編號唯一性、設定、月份及手動分頁；不接受較新版本備份。舊版物件與直接儀器陣列仍可匯入。
- 寫入前保留上一份完整原始快照，透過寫入日誌及失敗回復避免留下部分匯入。意外中斷時，下次載入會檢查日誌並回復；遇到無法安全判斷的資料則進入保護模式，不重設主檔。
- 「備份／還原」提供還原上次變更前資料與下載儲存原始資料。原始資料下載是故障診斷備份，不是一般匯入格式；正常搬移仍使用「匯出 JSON 備份」。
- 其他分頁變更資料後，本頁儲存會檢查衝突並拒絕覆蓋。這是樂觀衝突偵測，不是多人即時同步或伺服器交易系統。
- 主檔是清單、履歷及期限計算的共同來源。移除 25 份舊 ISO 範本對報表的覆蓋；對原先不一致的精密度、週期等值，不猜測或自動改寫，保留現有主檔，需依原始證書核實。
- 月份採「相同日期，目標月沒有該日則取月底」；例如 2025/1/31 加一個月是 2025/2/28。
- 期限顯示與使用判定分開。不合格、待複驗、停用、報廢或逾期禁止使用；資料不足顯示待確認。免校仍需確認使用狀況。這是根據系統紀錄的提示，不會自行認證儀器合格。
- 固定履歷主表保留原版面；超過 32 筆校驗、5 筆附件、12 筆維修／存放、4 項允差或誤差時，新增可列印續表，完整保留分項內容。長誤差文字也會附可閱讀明細。
- 一覽表手動頁數、編排與勾選會保存並納入 JSON 備份；修改量具編號時同步更新編排及人工月份設定。
- 動態按鈕改為資料屬性與事件監聽，不把儀器／設定文字拼進執行程式。CSV 對公式起始文字加純文字前綴。
- 提供模態視窗焦點限制、Escape 關閉及焦點返回；設定頁籤支援左右方向鍵、Home、End，排序表頭支援 Enter／空白鍵。未儲存履歷離開前會提示。

## 開發驗證

應用本身不需 npm。瀏覽器回歸測試使用 Node.js、`playwright-core@1.61.1` 及已安裝的 Chromium；工具可安裝在儲存庫之外：

```bash
npm install --prefix /workspace/.mims-tools --cache /workspace/.npm-cache --no-audit --no-fund --save-exact playwright-core@1.61.1
NODE_PATH=/workspace/.mims-tools/node_modules node --test tests/regression.cjs
```

測試從儲存庫根目錄執行，會自行啟動隨機連接埠的靜態伺服器，以隔離的瀏覽器資料驗證，無須先啟動應用服務。可用 `CHROMIUM_PATH` 指定瀏覽器位置。PDF 證據預設寫入 `/tmp/mims-regression`，可用 `MIMS_TEST_ARTIFACTS` 指定其他資料夾。

回歸涵蓋一般操作、錯誤匯入、模擬儲存失敗、快照復原、中斷寫入、特殊字元、日期邊界、履歷續表、跨分頁衝突、編排保存、鍵盤與響應式工具列。

實體印表機、Safari／Firefox、瀏覽器儲存配額的實際上限與極大量資料尚未驗證。
